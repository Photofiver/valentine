# QuickPrice

Narzędzie do szybkiego sprawdzania cen na CEX UK i eBay UK (w tym sprzedane przedmioty).

## Jak używać

```bash
python quickprice.py
```

Wpisz nazwę rzeczy (np. `iPhone 13`, `PS5`, `Airpods Pro`).

Skrypt automatycznie otworzy:
- CEX UK
- eBay UK (aktualne oferty)
- eBay UK **sprzedane** (to co się naprawdę sprzedało)

Idealny do używania na marketach typu Nut Corner Market.
